# StockVision – AI-Powered Stock Market Analysis Platform

StockVision is a full-stack, authentication-gated web application that provides real-time stock market data, interactive charts, multi-stock comparison, and AI-powered price predictions. Stock data is sourced from the Yahoo Finance v8 API and proxied through a Vercel serverless function. Predictions are generated by Google Gemini 1.5 Flash (when an API key is provided) or by a built-in technical-analysis algorithm, with results cached daily in Supabase. All pages are protected behind Supabase email/password authentication.

## Getting Started

These instructions will get a copy of the project running on a local machine for development and testing.

### Prerequisites

- [Node.js](https://nodejs.org/) ≥ 18
- npm ≥ 9
- A free [Supabase](https://supabase.com) account

### Installing

1. **Clone the repository**

   ```bash
   git clone https://github.com/jadhavvishakha613/StockAI.git
   cd StockAI
   ```

2. **Install dependencies**

   ```bash
   npm install
   ```

3. **Configure environment variables**

   Copy the example file and fill in your values:

   ```bash
   cp .env.example .env
   ```

   Edit `.env`:

   ```env
   VITE_SUPABASE_URL=https://your-project-id.supabase.co
   VITE_SUPABASE_PUBLISHABLE_KEY=your-anon-public-key

   # Optional — enables Gemini AI predictions
   VITE_GEMINI_API_KEY=your-gemini-api-key
   ```

   > `.env` is listed in `.gitignore` — never commit it.

4. **Set up the Supabase database**

   - Go to [supabase.com/dashboard](https://supabase.com/dashboard) and create a new project.
   - Open **SQL Editor**, paste the contents of `supabase/migrations/20250101000000_initial_schema.sql`, and click **Run**.

   This creates three tables (`profiles`, `stock_predictions`, `watchlists`) with Row Level Security enabled.

5. **Start the development server**

   ```bash
   npm run dev
   ```

### Running the Project

After starting the dev server, open [http://localhost:8080](http://localhost:8080) in your browser. You will be redirected to the sign-in page. Create an account to access the dashboard, stock predictions, comparison tool, and market insights pages. The Vite dev server automatically proxies all `/api/yahoo/*` requests to Yahoo Finance — no Vercel account is needed locally.

## Deployment

The project is deployed on [Vercel](https://vercel.com). To deploy your own instance:

1. Push the repository to GitHub.
2. Go to [vercel.com/new](https://vercel.com/new) and import the repository.
3. Vercel will detect the build settings from `vercel.json` automatically:
   - **Build command:** `npm run build`
   - **Output directory:** `dist`
   - **Install command:** `npm install`
4. Add the following environment variables under **Project Settings → Environment Variables**:

   | Key | Required |
   |---|---|
   | `VITE_SUPABASE_URL` | Yes |
   | `VITE_SUPABASE_PUBLISHABLE_KEY` | Yes |
   | `VITE_GEMINI_API_KEY` | Optional |

5. Click **Deploy**.

After deploying, add your Vercel domain to Supabase under **Authentication → URL Configuration** as both the Site URL and a Redirect URL.
